# Anti-Loop — downloads

Anti-Loop is a to-do list that ranks your tasks by what matters most, built
by BSCS 4C at ASU-Ibajay (Casidsid, Damo, Estolloso, Ricamonte).

**Get the newest version from [Releases](../../releases/latest).**

| Your device | File |
| --- | --- |
| Android (most phones) | `…-android-arm64-v8a.apk` |
| Android (older 32-bit phones) | `…-android-armeabi-v7a.apk` |
| Windows | `…-windows-portable.zip`: unzip, run `Anti-Loop.exe` |
| Linux | `…-linux.AppImage` |

Installing on Android: open the apk, and allow your browser to install apps
if Android asks. Updating: open the app → Settings → App updates. Your tasks
are kept.

This repository holds releases only.
